# 心晴 · 情绪日记与自我关怀 🌤️

> 低门槛记录情绪、看清规律、获得自助调节方案。面向学业 / 职场 / 社交压力下的年轻人，做「口袋里的心理急救箱」。
>
> 在线体验：https://lourdle.github.io/moodmate/

## 为什么做这个产品

年轻人的情绪困扰普遍而高频：考试季、职场落差、人际摩擦、睡眠失衡……但两侧的帮助都很贵——专业心理咨询成本高、预约难；而市面上的工具要么太重（问卷式的心理测评），要么太浅（单纯的打卡）。「心晴」想做一个**30 秒内完成记录、立刻得到回应**的轻量出口。

**核心设计原则**

1. **低门槛**：一次记录 < 30 秒。点一个 emoji 即可保存，文字可选，不设任何强制字段
2. **即时反馈**：保存当下即给予共情回应（按情绪等级的话术），有温度不冰冷
3. **隐私优先**：所有数据只存本地 localStorage，零上传、零账号、可一键导出与清除
4. **不替代专业**：定位为日常自我关怀，明确免责并引导持续低落者寻求专业帮助（附全国心理援助热线 12356）

## 功能地图

### 📔 记录（降低记录门槛）
- 首页问候卡：随时段问候 + 5 级 emoji 心情快选，hero 背景色随最近情绪变化
- 完整记录：情绪 + 强度滑条（1–10）+ 触发因素标签（学业/工作/人际/家庭/睡眠/健康/财务/其他）+ 自由文字
- 保存动效：emoji 飘落 + 共情话术反馈
- 最近记录流、连续记录 streak、深夜问候的时段感知

### 📊 洞察（让情绪看得见）
- **本周情绪周报**：本周 vs 上周均分（↑↓ 着色）、最多情绪、TOP 触发、峰值/低谷日、自动生成的叙事文案
- **30 天情绪日历**：贡献图风格热力图，颜色 = 当日平均情绪，悬停详情，今日高亮
- **时段情绪**：早晨/下午/晚上/深夜的平均情绪对比 + 针对性建议
- **文本分析**：70+ 关键词词典从日记文本自动识别触发因素（与手动标签合并排行）；高频词词云，点击词可下钻查看相关记录
- 近 7 天趋势折线、情绪分布、规则引擎生成的个性化洞察（共情、可执行，不贴标签）

### 🌿 关怀（提供可执行的自助方案）
- 依据最近一次情绪动态定制方案（低落 → 舒缓；平静 → 提神；开心 → 元气延续）
- **4-7-8 呼吸冥想**：呼吸节奏引导动画（4 轮自动引导）
- **5-4-3-2-1 着陆练习**：五感官分步交互，急性焦虑/思绪飘走时使用
- **白噪音**：雨声/海浪/风声由 Web Audio API 实时合成（零文件、零版权风险）
- **音乐处方**（网易云搜索直达）+ **运动处方**（B 站跟练直达）+ 随机「自我关怀小事」

## 技术实现

- 纯 HTML / CSS / 原生 JS，零依赖、零构建；图表均为手绘 SVG（无 CDN 依赖，国内访问稳定）
- 数据层：localStorage + 版本化 schema；导出/清空闭环
- PWA：可安装到桌面、离线可访问（manifest + service worker，网络优先策略保证迭代即时可见）
- 移动端优先：底部 Tab 导航、安全区适配、深浅主题（跟随系统/手动）

## 隐私说明

- 数据仅存储在你的浏览器本地，绝不上传任何服务器
- 支持 JSON 导出备份（当前为手动，路线图计划自动导入恢复）
