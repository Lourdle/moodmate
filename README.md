# 心晴 · 情绪日记与自我关怀 🌤️

> 低门槛记录情绪、看清规律、获得自助调节方案。面向学业 / 职场 / 社交压力下的年轻人，做「口袋里的心理急救箱」。
>
> 在线体验：https://lourdle.github.io/moodmate/

## 产品结构

- **📔 记录** — 30 秒快速打卡：emoji 情绪刻度（5 级）+ 强度滑条 + 触发因素标签 + 自由文字；首页问候卡、连续记录 streak 与最近记录流
- **📊 洞察** — 近 7 天趋势折线、情绪分布、高频触发因素排行，以及由规则引擎生成的个性化洞察文案（无需联网、隐私友好）
- **🌿 关怀** — 依据最近一次情绪定制方案：4-7-8 呼吸冥想引导动画、音乐处方（网易云）、运动处方（B 站演示）、随机「自我关怀小事」

## 技术

- 纯 HTML / CSS / ES Modules，零依赖、零构建，手绘 SVG 图表
- 数据全部保存在浏览器 localStorage，不上传任何服务器，保护用户隐私
- 移动端优先 + 深浅主题（跟随系统或手动切换）
